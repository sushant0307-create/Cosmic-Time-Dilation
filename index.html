SIMPLIFIED SCHWARZSCHILD MODEL

Clock-rate calculation

dτ / dt = √(1 − rs/r) × √(1 − v²/c²)

rs — Schwarzschild radius of the body

r — spacecraft distance from the body's centre

v — speed measured by a local stationary observer

c — speed of light

The rubber-sheet-style grid is a visual analogy, not a literal 4D spacetime diagram. The displayed grid distortion is intentionally exaggerated so it can be seen.
